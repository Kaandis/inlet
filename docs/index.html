Questions

Is it really free?

Yes. Inlet is open source under the MIT license. No trial, no upsell.

Which Macs does it run on?

Any Mac on macOS 15 or later. It’s made for the MacBook notch; on other displays a small island sits under the menu bar, and you can turn that off.

macOS says it can’t be opened.

Builds aren’t notarized yet. Right-click Inlet and choose Open, or run xattr -dr com.apple.quarantine /Applications/Inlet.app.

Is the song on this page real?

It’s generated live in your browser with the Web Audio API — no recording, no licence, no royalties. The Bezels are not a real band. Yet.

Does it collect any data?

No. The only network request is the weather widget, which sends the city you chose to Open-Meteo.

What languages does it speak?

English and Turkish, following your system — or pick one in Settings.
